# Denso and Elring source reconciliation — 17 November 2026

The Denso branch diverged after its catalog work and contains later prepared-export changes; the Denso official reader already exists on main. The Elring branch contains legacy completion and Spareto helper scripts plus ten migrations missing from main. All ten migration texts matched the corresponding already-applied production history checksums; they are restored as history and were not re-executed. Existing later main-branch changes, including the Elring collector credential handling, remain intact.

The historical admin prepared-export migration was also missing from main. Its branch file matched the applied production statement byte-for-byte, but the database recorded version `20261025201220`, so the restored file uses that actual version. The admin comparison and supplier price prewarmer was integrated into the current scheduled recovery without replacing customer batching or shared-follower guards. Successful profiles use existing source-change events and the same seven-day/future-boundary fallback as customer profiles; transient errors use a bounded retry. A failed asynchronous admin workbook requeues its current profile, since dispatch acceptance does not prove completion. The admin price-list handoff displays the existing file-ready success message.

Several previously applied Knorr, customer export and manual price migrations had local timestamps different from their production history; their contents matched production checksums and the files were renamed to their actual applied versions. Two existing production manual-price OEM migrations and their tests were restored from their source branch. No existing migration was re-executed.

Tests covered the Elring and Denso catalog readers, source identity, catalog completeness, collision checks, manual price/OEM safeguards, Knorr queue behavior, customer export guards, admin prewarm scope, scheduling and failure retries. A controlled production prewarm produced a 21-row catalog comparison workbook: the first attempt correctly stopped after its source version changed, and the second finalized successfully. Across this verification all 37 manual-price records and 31 supplier price publication pointers retained the same checksums. This is not a full reconciliation of every individual price.
